# 发布计划

## 当前模式

已完成首轮平台预览，没有公开发布。掘金和 LinkedIn 因平台自动保存机制已形成远程草稿；博客园和 Bilibili 保留在未提交的编辑器预览；V2EX 与小红书存在前置阻塞。详见 `preview-status.md`。

## 发布前置条件

1. 当前仓库改动完成 review、commit 和 push。
2. GitHub 链接能够展示本次新增文件。
3. XLSX 回算限制保留在长文和开发者平台版本中。
4. 分别检查平台预览、标题、正文、标签、链接和封面。
5. 用户对每个平台的最终 payload 和发布模式进行确认。

## 推荐顺序

1. 掘金：面向开发者的实现文章。
2. 博客园：完整技术复盘和验证证据。
3. V2EX：讨论中文触发回归方法，不写成广告。
4. Bilibili 专栏：纯文本结构，检查粘贴后的段落间距。
5. 小红书：短内容，建议封面文案“Skill 中文化 ≠ 翻译”。
6. LinkedIn：英文 operator note。
